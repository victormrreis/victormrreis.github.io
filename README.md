# Portfólio de Victor Martins Reis

Site pessoal estático, em português, publicado via GitHub Pages. O portfólio apresenta a experiência administrativa e operacional em ambiente industrial, a formação em Engenharia da Computação na UVA e projetos pessoais de tecnologia.

## Conteúdo

- `index.html`: página responsiva, estilos e interações em um único arquivo.
- `og-cover.svg`: imagem de compartilhamento Open Graph.
- `Curriculo_Victor_Martins_Reis_Principal.pdf`: currículo principal em PDF pesquisável.

## Publicação

O site não exige processo de build. Para atualizar o GitHub Pages, publique esses arquivos na raiz do repositório `victormrreis/victormrreis.github.io`.

As descrições de projeto qualificam o que é estudo, experimento ou iniciativa em desenvolvimento. Repositórios privados não são expostos na página pública.
